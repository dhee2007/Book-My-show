BOOKMYSHOW FOOD & DRINKS – ACADEMIC PROJECT PROTOTYPE

HOW TO RUN (NO VS CODE REQUIRED)
1. Extract the ZIP file to a folder on your computer.
2. Open the extracted folder.
3. Double-click index.html.
4. The project opens in Chrome, Edge, or another browser.

DEMO FEATURES
- Browse sample restaurants and menus.
- Search restaurants and menu items.
- Filter by cuisine and food type; sort by rating or price.
- Login / Sign up using a simulated OTP.
- Demo OTP: 1234
- Add, remove and update cart quantities.
- Choose Takeaway or Delivery.
- Apply FOOD10 (10%) or WELCOME5 (5%) demo discount.
- Simulated payment and order confirmation.
- Dine-In table reservation with date, time and guest count.
- View order and booking history.
- Restaurant manager demo dashboard.

IMPORTANT PROJECT NOTES
- This is a front-end prototype designed to run directly in a browser.
- Data is saved in the browser using localStorage.
- Login OTP and payment are simulations; no real SMS, payment, restaurant booking,
  or server/database connection is performed.
- Restaurant names and menu items are sample data for an academic demonstration.
- For a real production system, a secure backend, database, authentication provider,
  payment gateway and restaurant availability integration would be required.
